# RBLX-shared

Shared Luau framework consumed by **+1 Stilts** and **Evolve a Car**: networking, data,
economy, progression, monetization, UI kit, audio/VFX helpers, anti-exploit, admin,
localization, test and sim harnesses, and the asset manifest/uploader.

Nothing game-specific lives here. See `docs/STATUS.md` for current progress.
